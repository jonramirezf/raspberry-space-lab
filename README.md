# Raspberry Space Lab

Estación experimental con Raspberry Pi orientada a SDR, ADS-B, señales satelitales, telemetría y observabilidad.

## Objetivo

Construir una estación de monitoreo capaz de recibir, procesar y visualizar señales de radio.

La primera etapa estará enfocada en tráfico aéreo ADS-B en 1090 MHz. Posteriormente el proyecto se ampliará hacia recepción de señales satelitales, recopilación de telemetría y creación de dashboards para monitorear tanto las señales recibidas como el estado de la infraestructura.

## Tecnologías

- Raspberry Pi
- Linux
- SSH
- RTL-SDR
- ADS-B
- Python
- Docker
- Telemetría
- Dashboards
- Observabilidad

## Roadmap

- Preparación de la Raspberry Pi ✅
- Almacenamiento y acceso remoto ✅
- Análisis de señales y datasets públicos
- Visualización de señales y espectrogramas
- Integración RTL-SDR
- Recepción ADS-B en 1090 MHz
- Visualización de tráfico aéreo
- Recepción de señales satelitales
- Telemetría, métricas y dashboards
- Automatización y observabilidad

## Estado

Proyecto en desarrollo.

La Raspberry Pi ya se encuentra preparada para administración remota y cuenta con almacenamiento adicional para las siguientes etapas.
